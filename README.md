# Xnet - KiCad 10 差分等长分析插件

实时查看差分对等长，自动追踪电阻分割的 Xnet，计算串联电阻等效长度（两焊盘中心距）。

## 功能

- **差分对自动识别** — 自动解析 `_P/_N`、`+/-`、`P/N` 等命名规则的差分网络
- **Xnet 全链路追踪** — 自动跟踪电阻串联后的 Xnet，中间网络名不受 KiCad 自动命名影响
- **电阻等效长度** — 自动计算电阻两焊盘中心距，计入等长统计
- **实时监控** — 1 秒间隔自动刷新，仅结果变化时更新 UI
- **等长状态** — 绿/黄/红三色标注，默认容差：良好 <0.5mm，警告 <2.0mm

## 安装

1. 复制本目录到 KiCad 插件目录：
   ```
   %APPDATA%/kicad/10.0/scripting/plugins/Xnet/
   ```
2. 重启 KiCad，菜单 **工具 → 外部插件 → Xnet - 差分等长分析**

## 使用方法

1. 打开 PCB 文件
2. 运行插件
3. 自动显示所有差分对的等长数据

表格说明：

| 列 | 说明 |
|---|---|
| 差分分组 | 差分对基名 |
| 侧别 | P/N 分别占一行 |
| 网络 | 当前侧的网络名 |
| P(mm) / N(mm) | P/N 两侧全程线长（含电阻段） |
| 差值(mm) | P - N 差值 |
| 串联电阻 | 该侧串联的电阻信息 |
| R 等效(mm) | 电阻等效长度 |
| 等长状态 | √达标 / ~需调整 / ✗超差 |

## 要求

- KiCad 10.0+
- Python 3.x
- wxPython（KiCad 内置）
